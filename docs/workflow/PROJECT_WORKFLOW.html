wheel = zoom · drag = pan

▶ How a call flows

  • Operator uploads leads → leads → FRESH_CALL jobs → dispatcher claims → number allocator picks P1–P9 line → dial.
  • Vobiz answers → /vobiz/answer returns wss XML → /ws/vobiz → live session bridges audio to Gemini Live.
  • Hangup webhook → transcript → analyzer → disposition → 4-sandbox lifecycle schedules retries / WhatsApp / callbacks / feedback.

▶ Pipeline guardrails

  • DNC / opt-out register blocks callbacks & jobs (TRAI).
  • Slot guards, semaphores, inter-call gap (120–180s), hourly caps, line cooldown.
  • Strict lead-stage transition machine (workflow_models.py).

▶ Ops & delivery

  • Docker stack: technopoliss · openwa · postgres · caddy on VPS.
  • Self-healing: 10 health agents → Super Boss → Panther; Hermes watchdog cron.
  • Deploy: tar+scp → docker compose build && up -d (frontend baked into image).
